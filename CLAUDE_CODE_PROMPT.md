# Задача: доработка RanobeLib Downloader

Референс `parser` уже лежит в репозитории. Изучи его код и допили по ТЗ ниже.

---

## 1. Поддержка трёх сайтов

Программа должна работать с тремя источниками. Определяй сайт автоматически по домену в URL.

### ranobelib.me
Уже реализован в референсе. Подправь под остальные требования этого ТЗ (формат .docx, чистый текст, перевод названий).

### webnovel.com (новый)
Структура сайта:
- Страница книги → кнопка «Читать» открывает текст главы
- Режим «бесконечного полотна» — главы подгружаются при скролле вниз
- Через «Оглавление» — список всех глав, клик открывает конкретную главу
- Навигация между главами: листание вперёд/назад

**Важно:** webnovel сильно защищается от ботов. Подбери правильные `headers` (User-Agent, cookies и т.д.). Протестируй на нескольких главах.

### mvlempyr.io (новый)
Структура сайта:
- Страница книги → кнопка «Читать» и кнопка «Оглавление»
- URL глав нестандартный — вместо `/book/chapter-number` идёт сразу уникальный адрес главы
- Навигация кнопками «вперёд» / «назад»
- Оглавление — полный список глав для перехода

### Общие требования для всех сайтов:
- Вытягиваем **только чистый текст** главы
- Каждая глава = отдельный `.docx` файл
- Внутри docx — только параграфы текста, никаких заголовков, метаданных, имён переводчиков
- Имя файла: `Том N Глава N - Название.docx` (или `Глава N - Название.docx` если томов нет)
- Для новых сайтов — изучи их структуру, протестируй парсинг, подбери селекторы

## 2. Автоперевод названий глав (EN → RU)

Если название главы на английском — автоматически переводи на русский перед созданием файла.

- Библиотека: `googletrans==3.1.0a0` (самая стабильная версия, основная ветка глючит)
- Переводим только строку заголовка, не текст главы
- Если перевод не удался — оставляем оригинальное название, не крашим программу

---

## 3. Дизайн и стили (QSS)

### Геометрия
Скругления **НЕ ТРОГАЙ**. Оставь углы как в оригинальном референсе.

### Цвета
- **Фон**: чисто чёрный `#000000`
- **Кнопка «Скачать/Старт»**: яркий зелёный неон `#00ff88`
- **Кнопка «Стоп»**: яркий красный неон `#ff3050`
- **Остальные элементы** (рамки, лейблы, акценты): голубой/циан `#00f0ff`
- **Hover-эффект**: при наведении текст/рамка элемента разгорается неоном (ярче + glow)

### Прогресс-бар
Градиентное неоновое свечение — от циана к зелёному (или к фиолетовому). Главное — органично вписать в общую палитру.

---

## 4. Формат сохранения

- **Только `.docx`**. Никаких epub, fb2, txt.
- Одна глава = один файл
- Внутри файла — чистый текст параграфами, без мусора

---

## 5. Переименование файлов (отдельная секция в GUI)

Нужна кнопка/секция для пакетного переименования скачанных глав:
- Указать папку-источник (где скачанные файлы)
- Указать папку-назначение
- При нажатии — копирует все `.docx` в новую папку, убирая `Том N` из имени
- Пример: `Том 1 Глава 3 - Попои.docx` → `Глава 3 - Попои.docx`
- Кнопка «Превью» — показать в логе как будут выглядеть имена до/после

## План реализации

1. Обнови `requirements.txt`: добавь `python-docx`, `googletrans==3.1.0a0`
2. Модифицируй парсер — поддержка трёх доменов с автодетектом по URL
3. Добавь модуль перевода заголовков
4. Обнови GUI: цвета кнопок, фон, градиентный прогресс-бар, hover-эффекты
5. Добавь секцию переименования файлов в GUI
6. Протестируй каждый сайт на нескольких главах. Если что-то не работает — починить.

## Установка пакетов

У меня медленный интернет. Используй китайское зеркало:
```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple --trusted-host pypi.tuna.tsinghua.edu.cn
```

## Принципы кода

- Пиши простой, читаемый код. Каждая функция делает одну вещь.
- Не переусложняй. Если можно решить в 10 строк — не пиши 50.
- Обрабатывай ошибки: если одна глава не скачалась — логируй и иди дальше, не крашь всё.
- Давай осмысленные имена переменным и функциям.
- Комментарии — только там где неочевидная логика.
- Все строки интерфейса — на русском языке.
